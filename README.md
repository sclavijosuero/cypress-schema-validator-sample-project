# cypress-schema-validator-sample-project

Welcome to the Cypress-schema-validator Sample Project repository. This project serves as a demonstration of the features and best practices using the cypress-schema-validator Plugin.

## Overview

The **cypress-schema-validator** is a a sample project for the `cypress-schema-validator` plugin, designed for API testing. It validates API responses against plain JSON schemas, Swagger documents, or OpenAPI documents using the Ajv JSON Schema validator, and ZOD Schemas using the ZOD Validator.
